## Projects

### [Clawdiney](https://github.com/elaranjo/clawdiney)

An open-source memory layer for AI agents that makes an Obsidian vault searchable through MCP. It combines semantic and graph search to give agents access to project context and knowledge.

### [StorySpec](https://github.com/elaranjo/StorySpec)

A local narrative specification framework for novels and light novels. It helps writers organize requirements, continuity, planning, and review through a structured workflow. AI assistance is optional.

### Fit Lens

A virtual fitting product I founded, focused on helping shoppers visualize clothing. Building it has taken me from product decisions and user experience to e-commerce integration.

## How I use AI

I use tools such as Codex, Claude Code, and OpenCode to understand codebases, plan changes, and implement features. With OpenSpec, I define requirements and technical direction before execution. I also connect agents to tools through MCP to investigate errors, metrics, and usage.

Generated code is a proposal: I review it, test the relevant flows, and validate the result against the problem we set out to solve.
